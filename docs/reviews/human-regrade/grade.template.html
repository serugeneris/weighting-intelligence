Blind regrade: revision and transfer

36 saved replies from one small language model in three setups. You mark 72 pass or fail judgments without knowing which setup wrote which reply.

How to grade

The task

  • Each sheet is one short conversation. Text in the serif face is the model's reply; the rest is what it was asked.
  • Sheets R01 to R18 need three marks each. Sheets T01 to T18 need one.
  • Grade the reply against the rule shown beside it, not against how well it is written.
  • Every case appears three times with different replies. Grade each on its own.
  • A reply marked "cut off" hit its length limit. Grade what is there.

Keeping it blind

  • Do not open key.json, the findings or the earlier grades until you have exported.
  • Do not discuss the sheets with the case author while grading.
  • Use the note field when a call was close. Notes are exported with the marks.

Saving

  • Marks are kept in this browser as you go. That copy can be lost, so export before you close the page if you stop halfway.
  • To continue elsewhere, load your exported file with "Load grades".
  • When all 72 marks are in, send the exported file to the case author.
